## Ecosistema

- Siete apps de Studio Goya: Sandwich (19-08-2019), Classic, Chess (02-03-2020), Thermo (25-05-2020),
  Miracle, Killer, Arrow. Steam, iOS y Android; 4,99 $ cada una [B]
- Classic: 40 puzzles al salir y 5 al mes hasta 100, elegidos y probados por Simon y Mark [B]
- Classic: los puzzles avanzados, "diseñados para mostrar técnicas diabólicas de forma intuitiva" [B]
- App "Cracking the Cryptic" (2022): gratis, 7 puzzles de Prasanna Seshadri y packs de pago [B]
- Classic Sudoku Vol. 2: 60 puzzles; 20 de Nikoli, 20 de CTC y 20 de Sam Cappleman-Lynes [B]
- Catálogo de 22 productos: SudokuPad, las 7 apps, app CTC, Domino, Lines, GAS 1 y 2, Approachable,
  Fog of War, Classic 2 y la serie "Worm of…" (James Sinclair, Marty Sears, Phistomefel, Michael
  Lefkowitz, Blobz, Zetamath) [AP]
- Las apps posteriores a la app CTC necesitan la app CTC gratuita en iOS y Android [AP]
- Filosofía: "una vez has resuelto puzzles hechos a mano, no te conformarás con puzzles generados por
  máquina"; todos probados y con pistas de Simon y Mark [AP]
- SudokuPad: de Sven Neumann; web y apps en iOS, Amazon y Steam (11-2021) [B][SP]

## Classic Sudoku [G]

### Menús y progresión

- Lista de puzzles en 3 colores: sin resolver, resuelto, bloqueado
- Estrellas: resolver da estrellas; con suficientes se desbloquean puzzles
- Ficha del puzzle: dificultad de 1 a 10 estrellas, mejor tiempo, Continue (con el tiempo), New, Cancel
- "New" borra la partida guardada sin confirmación
- Orden de la lista: publicación, dificultad o estrellas necesarias
- "How to Play": reglas, trucos y herramientas

### Herramientas

| Herramienta | Uso |
|---|---|
| Selección múltiple | Mayús/Ctrl+clic, arrastrar; herramienta propia (Q) |
| Número / Esquina / Centro | A / S / D; Espacio cambia entre ellas |
| Varias celdas + número | Pone una nota del tipo por defecto |
| Marca X | E (herramienta), X (aplicar) |
| Resaltador de color | R (herramienta), C (aplicar) |
| Papelera | Borra todas las notas, todos los colores, todas las X, o reinicia conservando el tiempo |
| Goma | W, clic derecho o Supr |
| Deshacer / rehacer | N o Retroceso / M; varios niveles |
| Pistas | Botón "?" |

### Ajustes

| Ajuste | Opciones |
|---|---|
| Control Method | Selección primero / herramienta primero / "Classic" (mixto) |
| Display Timer | Visible / oculto; oculto sigue contando |
| Highlight Restricted Cells | Siempre / solo una celda / no. Con varias seleccionadas, resalta las que ven a todas |
| Highlight Matching Numbers | Números y notas / solo números / no |
| Cell Selection when dragging | Varias celdas / solo la primera / solo la última |
| Number Entry with Noted Cells | Escribir siempre / quitar primero la nota / escribir si es la última nota |
| Highlight Errors | Contra la solución / solo duplicados / no. Con la primera, el número completo se atenúa en el teclado |
| Display X in Cell | Vacías o con notas / solo vacías / siempre |
| Double Notation | Un tipo de nota por celda (se convierte al cambiar) / los dos a la vez |
| Default Note Style | Esquina / centro |
| Notes Size | Estándar / grande |
| Auto Remove Restricted Notes | Sí / no |
| Sync Save Data | Código con Merge u Overwrite; copiar al portapapeles |
| Themes | Temas de color |

### Ayudas de variantes

- Sandwich: combinaciones al pulsar una pista; se pueden descartar
- Killer: combinaciones de cada jaula; suma de varias jaulas y su distancia a un múltiplo de 45;
  calculadora libre
- Iconos por regla: caballo, rey, reina, no consecutivos, sándwich, flecha

## SudokuPad web [SP]

- Selección: clic o arrastre; Ctrl+clic añade o quita
- Ctrl/Mayús+flechas amplían la selección; Ctrl+A todo; Ctrl+Mayús+A ninguna; Ctrl+I invierte
- Doble toque o pulsación larga: selección según la herramienta (la página no dice cuál)
- Modos: Z dígito, X esquina, C centro, V color; Espacio y RePág/AvPág cambian de modo
- Ctrl+dígito centro, Mayús+dígito esquina, Ctrl+Mayús+dígito color
- Botón Check: comprueba las reglas básicas al terminar
- Sin verificar: reproducción de la resolución y comprobador de conflictos, citados en un informe de
  fallos antiguo de su repositorio [B]

## Opiniones de usuarios [B]

- Elogiado: notas de esquina y de centro; poca navegación entre modos de marcado; paleta personalizable
  (Classic); combinaciones de Killer
- Criticado:
  - Pistas escasas o erróneas en los puzzles difíciles
  - Precio por pack
  - Sin opciones para daltónicos
  - Teclas que no se pueden cambiar
  - Menús lentos con muchos puzzles resueltos; consumo de batería
- SudokuPad, criticado: un solo juego de colores; sin resaltar fila y columna al seleccionar un número;
  pérdida de puzzles en una actualización

## Comparativa con nona [G][N]

### Equivalencias

| Classic Sudoku | nona |
|---|---|
| Highlight Errors | Errores |
| Auto Remove Restricted Notes | Notas autolimpiables |
| Highlight Restricted Cells | Sombreado de zona |
| Highlight Matching Numbers | Resaltado de dígito |
| Control Method | Celda primero / número primero |
| Display Timer | Ocultar el reloj |
| Atenuado en el teclado | Dígitos completos atenuados |
| Sync con Merge y Overwrite | Export / Import con Merge y Replace |
| Temas | Tema y acentos |

### Lo que tienen y nona no

- Notas de esquina más centro
- Selección múltiple
- Opciones al escribir en una celda con notas
- Papelera por capas y reinicio
- Marca X
- Tamaño de notas aparte
- Lista de puzzles con dificultad 1–10 y orden
- Ayudas de variantes
- Variantes

### Lo que tiene nona y ellos no

- Pistas del motor, explicadas en 3 pasos, en todos los puzzles
- Sudoku del día con calendario
- Puzzle propio
- Estadísticas de actividad y XP
- Pausa que oculta el tablero
- Acento personalizado
- Vibración
- Gratis, web, sin conexión

### Teclas

- Copiar las de SudokuPad choca con nona: C es color en nona (V en SudokuPad); Espacio es pausa en nona
  (cambio de modo en SudokuPad) [N][SP]

## Propuestas

| Prioridad | Propuesta |
|---|---|
| 1 | Notas de esquina más centro, con ajuste de una o dos notaciones por celda |
| 2 | Selección múltiple, con resaltado de las celdas que ven a todas las seleccionadas |
| 3 | Opción "escribir directamente si es la última nota" |
| 4 | Borrar todos los colores y reiniciar la partida |
| 5 | Practicar una técnica, con puzzles elegidos por el motor |

- Descartadas por aportar poco a nona: marca X, tamaño de notas aparte, lista de puzzles con orden
- Fuera: variantes; el motor solo resuelve el clásico
